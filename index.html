빗소리 업로더 (Rain Sound Uploader)

이 앱은 YouTube 채널 편한 잠자리 연구소, 연금, 보험 절세노트의 운영자가 직접 만든 개인용 업로드 도구입니다. 빗소리 수면 영상과 연금·보험 정보 영상을 제작해 운영자 본인의 YouTube 채널에 예약 업로드하고, 썸네일·재생목록을 설정하며, 채널 통계를 확인합니다.

This is a personal tool used only by the owner of the YouTube channels "편한 잠자리 연구소" and "연금, 보험 절세노트" to upload videos to their own channels via the YouTube Data API. It is not offered to the public.

사용하는 Google API

  • YouTube Data API v3 — 동영상 업로드, 썸네일·재생목록 설정, 채널 정보 조회
  • YouTube Analytics API — 채널 시청 시간 조회 (읽기 전용)
