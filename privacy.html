개인정보처리방침 (Privacy Policy)

오교신 빗소리 업로더(이하 "앱")는 YouTube 채널 운영자 본인만 사용하는 개인용 도구입니다.

1. 접근하는 정보

앱은 운영자가 Google 로그인으로 허용한 범위에서만 다음 정보에 접근합니다: YouTube 채널 정보(채널 ID·이름·통계), 운영자가 업로드하는 동영상·썸네일·재생목록, 채널 시청 시간 통계(읽기 전용).

2. 이용 목적

운영자 본인 채널에 동영상을 업로드하고 관리하며, 채널 성과를 확인하는 목적으로만 사용합니다.

3. 보관 및 공유

로그인 토큰은 운영자 본인의 PC에만 저장되며 외부 서버로 전송하지 않습니다. 앱은 어떠한 정보도 제3자에게 판매·공유·제공하지 않으며, 광고 목적으로 사용하지 않습니다. Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 접근 권한 철회

언제든지 Google 계정 → 타사 앱 액세스에서 앱의 권한을 삭제할 수 있으며, 이 경우 PC에 저장된 토큰도 더 이상 사용할 수 없습니다.

5. 문의

문의는 YouTube 채널 오교신을 통해 남겨 주세요.

English summary

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
